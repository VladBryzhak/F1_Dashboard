# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

F1 Dashboard — a web-based Formula 1 data dashboard. Currently in early scaffolding; the only deliverable so far is a bare `index.html`.

## Stack

Plain HTML/CSS/JS at the moment. No build tool, bundler, or package manager has been introduced yet.

## Running locally

Open `index.html` directly in a browser, or serve it with any static file server, e.g.:

```bash
npx serve .
# or
python -m http.server
```
